## 🔧 Key Features

### 🎭 Emotional Spectrum Tuner
- Fine-tune mood intensity values (from subtle shadow to vibrant glow) for individual Sims or entire households.
- Create **emotion storm events** that gradually build or dissipate over in-game hours rather than flipping instantly.
- Save custom mood presets and share them as `.spectrum` files within your community.

### 🏗️ Architectural Palette Expander
- Unlock hidden build-mode objects and wall patterns that were intended for future patches but left dormant in the game data.
- Adjust object placement collision thresholds to allow **impossible art installations** (floating bookshelves, overlapping rugs).
- Clone any terrain paint or swatch with a single keystroke, perfect for regional landscaping variety.

### ⏳ Temporal Reimaginer
- Rewind a Sim's skill progression to any historical checkpoint—not just full resets, but **partial rollbacks** (e.g., lose only 2 levels of cooking from three weeks ago).
- Slow or accelerate specific life stages independently (teenager aging at 50% while elders remain normal).
- Schedule **temporal anchors** that freeze a Sim's needs temporarily during significant narrative moments (weddings, funerals).

### 🧪 Interaction Frequency Manipulator
- Adjust the probability weights of autonomous interactions, so a Sim who loves painting actually paints more often without player prompting.
- Create **social butterflies** or **reclusive artists** by modifying conversation initiation vectors.
- Track interaction statistics in a floating overlay panel for data-driven storytelling.

### 📚 Knowledge Vault
- Export your entire Sim's biography (memories, relationships, career history) to a readable text timeline.
- Import custom memories from text files to inject backstory that never existed in-game.
- Generate **relationship heatmaps** showing who influences whom in a household.

### 🎨 Visual Mood Lighting Controller
- Override in-game lighting temperature values simultaneously across all lots.
- Create **photography-perfect golden hour** conditions that persist for exactly 15 in-game minutes.
- Apply cinematic color grading presets that affect only screenshots, not live gameplay.

## 🚀 Getting Started Guide

### System Preparation
1. Ensure your Sims 4 game client is updated to the latest **2026 seasonal patch**.
2. Run the game once after installation of the toolkit—it will detect your data directory automatically.
3. Open the companion application (available for Windows 10/11 and macOS Monterey+).

### First Launch Experience
Upon starting, Spectrum Weaver performs a **silent health check**, verifying your save files and creating a rollback snapshot. You'll see a welcome dashboard with three primary action zones:

- **Quick Adjust** – For the most common toggles (needs fill, relationship boost).
- **Recipe Library** – Pre-made scenario bundles (e.g., "Rags to Riches Stressful" or "Perfect Family Drama").
- **Script Forge** – The advanced area where you combine raw parameters.

### Workflow Example: Crafting a Rainy Day Narrative
1. Open the Emotional Spectrum Tuner and shift the global sadness weight to +20%.
2. Use the Temporal Reimaginer to set your Sim's energy drain rate to 1.3x for 24 sim-hours.
3. Apply the "Blurred Skies" lighting preset from the Visual Mood Controller.
4. Result: A melancholic atmosphere that makes an indoor painting session feel like a scene from a Nordic noir film.

## 🧩 Advanced Configuration

Spectrum Weaver uses a modular **JSON-based parameter tree** for power users. Each module can be toggled independently, and the entire configuration file is human-readable and commented by default.

### Module Aliases
`emotion-spectrum`, `arch-palette`, `temporal-reimaginer`, `interaction-mixer`, `knowledge-vault`, `light-director`

### Sample Snippet
```json
{
  "emotion-spectrum": {
    "global_mood_scale": 1.2,
    "seasonal_emotional_memory": true,
    "storm_duration_minutes": 45
  },
  "temporal-reimaginer": {
    "aging_rate_multiplier": 0.85,
    "skill_rollback_depth": 3
  }
}
```
